# Night Lord publication projection

This source adds the explicit `night_lord` / `Night Lord` metadata mapping to the
public projector. It is based on the scoped Night Lord runtime source and does
not change its controller, model configuration, native recipe, scoring, trial,
admission, or ordinary persistence logic.

A separately pinned publication source may read an existing hash-pinned runtime
plan. The plan, requested model identities, attempt IDs, native save receipts,
all adaptive cycles, and original recordings remain the inputs to the existing
verification. Publication does not acquire a game claim, replay an API request,
or turn a scripted native check into a model result.

Use an immutable publication source path and its exact commit when preparing the
public package. Keep the plan's original runtime source reference unchanged.
The multi-class catalog can then consume the verified package through its
existing four-class support. This projection source does not itself expand the
catalog or deploy anything.

The focused tests use synthetic receipt fixtures and mocked video probing.
Passing them establishes metadata/provenance handling, not actual Night Lord
qualification. Real projectile damage, ordinary star consumption, and the
separate native acceptance review are still required before a model cohort.
Shadow Partner remains excluded from the scoped fixture.
