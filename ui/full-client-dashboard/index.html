Simulation labInside the distributed setup

What the agent sees

Position, HP/MP, XP, level, map, alive status, and nearby monsters. The model receives structured state; the recording is for us.

What it controls

A program calls observe(), pressKeys(), and wait() in Node.js / Docker. Normal game inputs only; no stat edits.

An agent’s program Illustrative

const state = await sdk.observe();
if (state.character.hp < state.character.maxHp / 2) {
  await sdk.pressKeys(['HP_POTION'], 100);
}
await sdk.pressKeys(['LEFT'], 300);
await sdk.pressKeys(['BRANDISH'], 650);

Each worker owns its world, database, baseline, credentials, and locks. Trials run serially per worker; cohorts stay on one host. Provisioning alone does not establish qualification. An external controller verifies worker deletion at lease expiry.

Methodology

Score

Saved XP after logout minus starting XP, including penalties. Live XP is diagnostic. Missing scores stay missing.

Comparisons

Groups share a baseline, scenario, budgets, and runtime settings. Live scenes can differ. Small samples do not establish statistical significance.

Evidence

Input and publication checks are separate from scores. Failed, recovered, and zero-input attempts remain in the history.
